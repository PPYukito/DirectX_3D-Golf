## ⛳ 3D Golf Game
My first 3D game development project using **C++ and DirectX**. This project is a golf-hitting game where the player launches a physics-based ball through a procedurally constructed course filled with obstacles, aiming to reach the flag with as few hits as possible.

Developed with guidance from a teacher, this project gave me practical experience with 3D rendering, physics-based movement, collision detection, runtime object placement, camera systems, and rendering transitions. I also adapted and implemented additional features to expand the original project.

## ⚙️ Technical Highlights
- Graphics API: DirectX — version to be specified
- Programming Language: C++
- Platform: Windows Desktop
- Physics-based ball movement using velocity
- Hit counter to track the number of shots
- Runtime golf course generation using cube objects and calculated positions
- Randomized obstacle placement with collision detection
- Multiple cameras with collider-based camera tracking zones
- Camera-facing 2D mesh flag rendered within the 3D scene
- Randomized tree model placement to create course
